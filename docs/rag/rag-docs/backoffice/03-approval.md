# PMart 변경 요청·승인 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 백오피스에서 상품·가격·전시·권한 등 중요한 정보를 바꿀 때 거치는 변경 요청과 승인, 승인 결과의 반영에 관한 기준을 정합니다.

## 제2조 (승인이 필요한 변경과 승인자)
다음 변경은 정해진 승인자의 승인을 받아야 효력이 생깁니다.

| 변경 | 승인자 |
|---|---|
| 상품·판매 단위·바코드·카테고리 변경, 판매중지 | 상품 승인자 |
| 고객에게 보이는 상품명·설명·이미지 게시, 홈 배너·테마 편성 | 전시 승인자 |
| 기본 판매가격 | 가격 승인자 |
| 고객 배송 권역·담당 센터 | 배송 권역 승인자 |
| 센터 기준정보·영업 일정 | 센터 기준정보 승인자 |
| 센터 초기 재고 반입 | 재고 승인자 |
| 센터 재고 조정·폐기·격리 해제 중 본사 승인 기준 이상인 것 | 재고 승인자 |
| 센터 운영 제한 해제 | 운영 관리자 |
| 직원 권한 추가·변경 | 운영 관리자 |
| 검색 동의어 | 운영 관리자 |

1. 승인자가 정해지지 않은 종류의 변경은 승인할 수 없습니다.
2. 검색 동의어 변경은 MD 또는 운영 관리자만 요청할 수 있습니다. 그 밖의 변경을 누가 요청할 수 있는지는 각 업무 정책을 따릅니다.
3. 센터 재고 조정의 본사 승인 기준은 MFC 재고·품질 정책을 따릅니다.

## 제3조 (자기 승인 금지)
1. 변경을 요청한 사람은 그 요청을 승인할 수 없습니다.
2. 직원 권한 요청은 그 권한을 받을 본인이 승인할 수 없습니다.
3. 센터 운영 제한 해제나 재고 조정처럼 승인 번호를 받아 실행하는 변경은, 승인한 사람이 직접 실행할 수 없습니다.

## 제4조 (요청과 제출)
1. 요청자는 바꿀 내용을 초안으로 만든 뒤 제출합니다. 제출하면 그 내용이 잠기며, 잠긴 내용 그대로 승인 심사를 받습니다.
2. 같은 대상에 대해 심사 중인 승인은 한 번에 하나만 둘 수 있습니다. 앞의 승인이 결정된 뒤 새로 요청합니다.
3. 초안을 고치는 동안에는 고객 화면이나 업무에 아무 영향이 없습니다.

## 제5조 (승인함과 결정)
1. 승인자는 백오피스 승인함에서 자기가 결정할 수 있는 요청을 보고 승인하거나 반려합니다.
2. 승인함은 각 요청마다 보는 사람이 결정할 수 있는지와, 결정할 수 없다면 그 이유(이미 결정됨, 자기 요청, 승인 역할 없음, 본인 권한 요청 등)를 보여 줍니다.
3. 반려된 요청은 반영되지 않습니다. 요청자는 내용을 고쳐 새로 제출합니다.

## 제6조 (반영)
1. 승인된 변경은 그 정보를 관리하는 업무 시스템이 자동으로 반영합니다. 승인 뒤에 직원이 따로 반영 버튼을 누르지 않습니다.
2. 제출 뒤에 대상이 다른 변경으로 바뀌어 승인된 내용과 지금 상태가 맞지 않으면, 그 승인은 반영되지 않습니다. 이때는 지금 상태를 기준으로 다시 요청합니다.
3. 반영 결과(반영됨, 일부 반영, 반영 안 됨과 그 사유)는 승인 상세에서 확인할 수 있습니다.
4. 승인 번호를 받아 실행하는 변경은 승인 번호 하나를 한 번만 쓸 수 있으며, 승인된 대상과 범위 안에서만 쓸 수 있습니다.

## 제7조 (자동 승인)
1. 회사가 미리 정한 자동 승인 규칙에 맞는 요청은 사람의 심사 없이 바로 승인됩니다. 지금 자동 승인 규칙은 센터 작업자 역할을 소속 센터 하나에만 주는 권한 요청 하나뿐입니다.
2. 자동 승인된 요청은 어떤 규칙으로 승인되었는지 기록에 남습니다.

## 제8조 (기록)
요청, 제출, 승인, 반려, 반영 결과는 요청자·승인자·시각과 함께 기록으로 남습니다.
