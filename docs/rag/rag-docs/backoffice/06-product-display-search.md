# PMart 상품·전시·검색 운영 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 MD와 각 승인자가 백오피스에서 상품, 가격, 고객용 상품 콘텐츠, 홈 진열, 검색 동의어를 등록하고 바꾸는 기준을 정합니다.

## 제2조 (상품 등록과 변경)
1. 상품·판매 단위·바코드·카테고리의 등록과 변경은 MD 또는 운영 관리자가 초안으로 만들고, 상품 승인자의 승인을 받아야 반영됩니다.
2. 이미 등록된 상품을 다시 올리면 새 상품이 아니라 기존 상품의 새 버전으로 반영됩니다.
3. 상품 정보에 중량이나 보관 온도가 빠져 있으면 회사가 추정해서 채우지 않으며, 담당 직원이 백오피스에서 직접 채웁니다.
4. 카테고리를 더할 때는 지금 쓰는 카테고리를 그대로 두고 없는 항목만 더합니다. 승인 전에 다른 카테고리 변경이 먼저 반영되면 그 초안은 다시 만들어야 합니다.

## 제3조 (판매 상태)
1. 상품의 판매 상태는 MD만 바꿀 수 있습니다.
2. 일시품절과 판매 재개는 바로 반영됩니다.
3. 판매중지는 상품 승인자의 승인을 받아야 반영됩니다.
4. 상품 정보를 다시 올려 승인받더라도 판매중지 상태는 저절로 풀리지 않습니다.

## 제4조 (가격)
1. 기본 판매가격은 가격 승인자의 승인을 거쳐서만 바뀝니다.
2. 가격을 한꺼번에 올릴 때는 지금 가격과 달라진 판매 단위와 가격이 없던 판매 단위만 승인 요청에 들어가며, 가격이 같은 줄은 빠집니다.
3. 가격을 한꺼번에 올릴 때 담당 직원은 줄마다 가격을 고치거나 줄을 빼고, 모든 줄에 같은 적용 시각을 정할 수 있습니다.
4. 적용 시각을 정하지 않은 가격은 승인이 반영된 때부터 적용됩니다.

## 제5조 (고객용 상품 콘텐츠)
1. 고객에게 보이는 상품명·설명·이미지는 MD 또는 운영 관리자가 초안으로 만들고, 전시 승인자의 승인을 받아야 게시됩니다. 승인 없이 따로 게시하는 방법은 없습니다.
2. 게시 전 초안의 이미지는 직원만 볼 수 있습니다.

## 제6조 (홈 배너·테마 편성)
1. 홈 화면의 배너와 상품 테마(테마·계절·주간 추천)는 MD 또는 운영 관리자가 편성 초안으로 만들고, 전시 승인자의 승인을 받아야 고객 화면에 나갑니다.
2. 초안을 고치는 동안에는 고객 화면이 바뀌지 않습니다. 제출하면 초안이 잠기고, 잠긴 내용 그대로 심사를 받습니다.
3. 다음 중 하나라도 맞지 않으면 제출할 수 없으며, 걸린 곳을 한 번에 모두 알려 줍니다.
   - 테마에 넣은 상품이 게시되어 있고 판매중지가 아닐 것
   - 배너 이미지가 올라가 있을 것
   - 링크 대상이 올바를 것
   - 시작 시각이 끝 시각보다 앞설 것
   - 같은 배너나 테마를 두 번 넣지 않고, 한 테마 안에 같은 상품을 두 번 넣지 않을 것
   - 제4항의 금지 문구가 없을 것
4. 지금은 할인·쿠폰·특가 행사를 홈 편성으로 알리지 않습니다. 배너·테마의 제목, 부제, 대체 문구에 다음 표현을 쓸 수 없습니다.
   - 할인, "N% off", 쿠폰, 특가, 증정, 사은품, 1+1, 세일
   - 근거 없는 "최저가", "신선 보장"
   - "100% 국내산"처럼 할인이 아닌 백분율 표현은 쓸 수 있습니다.
5. 한 테마에는 상품을 1개 이상 50개 이하로 넣으며, 넣은 순서대로 보입니다. 판매중지되거나 그 센터에서 취급하지 않는 상품은 고객 화면에서 빠집니다.
6. 배너 이미지는 JPEG·PNG·WEBP 형식, 5MB 이하만 올릴 수 있습니다.
7. 게시된 편성은 고치지 않습니다. 바꾸려면 새 초안을 만들어 새 버전으로 승인받습니다. 배너·테마를 내리려면 그것을 뺀 새 편성을 승인받거나 끝 시각을 정합니다. 이전 버전과 승인 기록은 남습니다.

## 제7조 (검색 동의어)
1. 검색 동의어(예: 계란, 달걀)는 MD 또는 운영 관리자가 요청하고, 운영 관리자가 승인합니다. 요청한 사람은 자기 요청을 승인할 수 없습니다.
2. 동의어는 같은 뜻을 가진 낱말 묶음으로만 등록합니다. 한쪽 방향으로만 바꿔 찾는 규칙은 등록할 수 없습니다.
3. 심사 중인 동의어 요청은 한 번에 하나만 둘 수 있습니다.
4. 요청한 뒤에 다른 동의어 변경이 먼저 반영되면 그 요청은 반영되지 않으며, 지금 목록을 기준으로 다시 요청합니다.
5. 승인된 동의어는 바로 검색에 반영됩니다.
