# 2026-11-20 mfc (PC 3)

## 포장 인계 번호 4자리 + 5번 잠금 (MFC 시뮬레이터 R-26, mfc-fulfillment 0.23.0 V19, #257 위)
- 시뮬레이터 R-26: 라이더 번호 인계(F-8) 번호를 6자리 → 2~4자리, 틀린 입력 잠금. 사용자 결정 "앞으로 발생하는 주문 인계 번호는 다 4자리" — 자동 늘림 없이 4자리 고정.
- 번호: 포장을 넣을 때(밀봉·재포장·재구성 세 경로 `TaskStore.assignHandoverCode`) 센터마다 트랜잭션 잠금을 잡고, 같은 센터의 OPEN·SEALED 포장이 쓰지 않는 4자리 중 무작위. 남은 번호가 없으면 DB 기본값(4자리 무작위). 옛 6자리 포장은 그대로, 입력 pattern `^([0-9]{4}|[0-9]{6})$`.
- 잠금: `handover_code_attempt`(라이더·배송별 실패 수), 5번 틀리면 409 HANDOVER_CODE_LOCKED(맞는 번호도 거절), 틀림에 details attemptsLeft. 5번 = 반납 인증번호(delivery-execution)와 같은 기준.
- 회신 `docs/handoff/simulator/mfc/2026-11-20-simulator-reply-r26-handover-code.md`, 앱 알림 `docs/handoff/clients/all/2026-11-20-notice-handover-code-4.md`(라이더 앱 세션에 알림 — 회신: 지금은 이 API 를 안 부름, 번호 입력을 넣을지 PC 5 가 사용자에게 물음).
