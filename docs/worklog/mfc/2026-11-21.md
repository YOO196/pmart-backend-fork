## MFC 평면 재배치 — 모든 칸 위치 다시 등록 (MFC 시뮬레이터 R-34 — 서버 변경 없음, LAN seed, 브랜치 `mfc/r34-relayout`)
- **요청**: 시뮬 세션(시뮬레이터 f51a4db). 사용자 결정 "입고구역 근처에 냉동냉장구역이 있어야" — 구역마다 통째로 평행 이동한 것이고, 칸 코드·랙·면적은 그대로다.
- **LAN 읽기 확인**: #330·#331 은 병합됐고 PC 1 이 실행했다(R1 ACTIVE 900·CLOSED 90, R2 ACTIVE 16·CLOSED 4, RCV-A-02 44.0·6.05). 파일 15,534칸은 모두 LAN 에 있고, 좌표는 모두 다르다.
- **LAN seed**(`mfc_layout.py`)
  - 위치 파일 사본 `docs/simulator/mfc/layout/location-positions.json` 을 넣었다.
  - 새 `r34` 단계는 위치만 PUT 한다. 속성·상태는 그대로다.

  - 좌표 비교는 `same_pos`(소수 둘째 자리 허용 오차)로 한곳에 모았다.
  - RTN-A-01 은 파일에 없어서 그대로 둔다(새 자리 확인 필요).
- **PC 1 실행**: `python -I deploy/lan/seed/mfc_layout.py r34`(예상: 바꿈 15,534, 실패 0, 30~40분).
- **회신**: `docs/handoff/simulator/mfc/2026-11-21-simulator-reply-r34-relayout.md`.
- **시험**: `py_compile` 만 했다.
