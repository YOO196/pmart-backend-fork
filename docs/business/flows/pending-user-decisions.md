## 정해진 것 (2026-11-08)
- **고객 자율 취소 마감**(사용자 2026-11-09, ADR-0052): 고객은 주문이 **상품준비(피킹 시작) 전까지** 앱 주문 내역에서 스스로 취소. ~~상품준비 뒤는 고객센터 문의로 접수, 출고 중지 확인된 미인계 수량만 취소.~~ → **ADR-0060(2026-11-13)**: 상품준비 뒤 ~ 인계 전 고객 요청 취소는 고객센터로도 받지 않음(시스템 결품 취소만). 인계 뒤 회수(D-7)는 그대로.
- **오배송 처리 흐름**(사용자 2026-11-09, ADR-0052): 오배송이 **확인되면**(라이더 확인·사진 위치 다름·잘못 받은 사람 연락 중 하나) 새 발송(MFC 재포장 → 원주소, 비용 0원, 재고 부족 품목은 부분 환불)과 회수(인근 라이더 자동 배차 → MFC 반납, 신선 폐기)를 **동시에**. 고객 진술만이면 고객센터 문의 접수. 자동 배차는 DD-1 구현 뒤.
- **입고량 기준**(사용자: "그래" — 추천안 그대로):
  - 계획 기준 = **하루 154박스**(기준안 134 + 15%) → 오전 3명(검수 2·하차·이동 1). 실제 입고가 2~4주 쌓이면 실측 평균으로 바꾼다.
  - 수령창 상한 = 1회 **360**박스(원문 한 차수 처리 목표 9팔레트), 하루 **720**(오전 차량 2대 — 원문 543행 확정 조건 "2대 이상", 2026-11-08 정정: 처음에 1대로 잘못 말함), 하차면 **1**(검수장 하나, 차는 순서대로), 07:00~10:00.
  - 박스당 12개는 계획용 환산만(수령 예약은 박스 수를 직접 받음). 판매 예상량 → 박스 환산 때는 상품별 실제 박스 입수로 바꾼다.
- **#5 보류된 예약의 고객 처리**(사용자: 1 C, 2 그래, 3·4 요청 문서로):
  - 피킹 시작 전 = 자동 재확보(1분 주기, 재확보 순서 그대로) → 다 잡히면 확인 필요 자동 종결.

  - **결품은 고객 사전 선택과 관계없이 무조건 부분 취소·환불**(사용자 정정, ADR-0049). 남은 상품이 하나도 없을 때만 전체 취소(내 판단 — 바꿀 수 있음). 상신·CS 이관 없음. 대체 상품 없음.
