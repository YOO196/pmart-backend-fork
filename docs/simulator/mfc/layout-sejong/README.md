  2. **입고·검수는 반드시 냉동 근처** — 맨 왼쪽 열에 **화물 승강기 → 입고·검수 → 휴게·사무**, 그 바로 옆에 냉동 A(입고·검수와 벽 하나, 문으로 이어짐), 이어서 냉장 B.
  3. **패킹대 바로 옆(북쪽)에 상온 C~H**.
  4. **휴게·사무는 18평 고정**(비율로 늘리지 않음, 사용자 4차). 남는 13.6평은 공용 바닥.
  5. **화물 승강기 바깥(서쪽) 1층에 입고 차량 진입로**(사용자 4차) — 차량이 승강기 아래에서 내리고 3층으로 올린다.

## 구조 (서쪽 → 동쪽)

- **북쪽 통로(폭 2.4 m)**: 북쪽 벽을 따라 왼쪽 열·냉동·냉장 위를 지나 상온 서쪽 문까지. 입고·검수와 냉동·냉장 문이 모두 여기로 열린다(사용자 6차 "세종에 북쪽 통로가 없네").
- **맨 왼쪽 열**: 위 입고·검수(북쪽 통로 문) → 화물 승강기 2대(서쪽 문 = 1층 진입로, 북쪽 문 = 입고·검수) → 휴게·사무 18평. 동쪽 1.3 m 통로가 입고·검수와 휴게·사무를 잇는다.
- **냉동 A · 냉장 B**: 북쪽 통로 쪽 **북쪽 문(입고) + 남쪽 문(피킹) 두 개**(사용자 7차). 랙은 방 북쪽, 남쪽에 보충재고 팔레트·격리실. **남쪽 통로**(세종 2.4 m·창원 1.8 m)가 남쪽 문과 가운데 작업 바닥(상온·패킹)을 잇는다(사용자 7차 "왜 남쪽 통로를 또 없앴니").
- **냉장 동쪽 세로 통로(1.4 m, 사용자 8차 — 부산 진구점 새 평면 참고)**: 북쪽 통로 ↔ 남쪽 통로, 작업자 대기 줄.
- **가운데**: 상온 C~H · 패킹(7대 × 2줄) · 출하대기를 **벽 없이 한 바닥**(서쪽은 세로 통로로 열림).
- **동쪽 끝**: 입고창고(서쪽 벽 문 둘 = 상온 줄 끝·패킹 쪽, 상온 격리).
- **건물 밖 서쪽 1층**: 입고 차량 진입로(화물 승강기 바로 아래).

## 동선·문 (사용자 6·7차 — 입고는 북쪽 문, 피킹은 남쪽 문)

| 흐름 | 길 |
|---|---|
| 입고(저온) | 1층 진입로 → 화물 승강기 → 입고·검수 → **북쪽 통로 → 냉동·냉장 북쪽 문** |
| 입고(상온) | 입고·검수 → 북쪽 통로 → 세로 통로 → 상온·패킹 바닥 → 입고창고 서쪽 문 |

| 피킹 | 패킹 ↔ 상온: 벽 없음. 냉동·냉장: 작업 바닥 → **남쪽 통로 → 각 방 남쪽 문**(동쪽 끝, 패킹 쪽) |
| 출하 | 패킹 ↔ 출하대기: 벽 없음 → 라이더 픽업 |

## 열린 가정 (사용자 확인 필요)

1. 3층 한 층 전체 사용, 층고 충분. 건물 모양은 실제 도면이 오면 평수를 지키며 맞춘다.
2. 화물 승강기 2대의 위치(서북쪽)와 크기(45 ㎡).
3. 라이더가 승객용 승강기로 3층 출하대기까지 올라온다.
