# 회신 — R-35 냉동·냉장 피킹 랙 줄 재구성 (2026-11-22, PC 3 mfc)

보낸 영역: mfc(PC 3). 요청: pmart-mfc-simulation `docs/backend-requests.md` R-35(시뮬레이터 main c6745ab). 사용자 결정 2026-11-22 "2번" — 랙을 남쪽 빈 곳까지 늘려 줄 수를 줄인다(줄마다 21랙, 냉동 A 6→5줄, 냉장 B 7→6줄).

## 1. 바꾼 것 — LAN seed `deploy/lan/seed/mfc_layout.py`(서버 코드 변경 없음)
- **새 단계 `r35`**. 목록은 `docs/simulator/mfc/layout/r35-cold-rows.json`(시뮬레이터 c6745ab 사본)이다.
  1. **새 칸 1,045 등록**: F-A1~A5 랙 19~21(450), C-B1~B5 랙 19~21(525), C-B6 랙 19~20(70).
     - zone STORAGE, 일반 선반(highTurnover·reserveStock false).
     - 위치는 파일 xM·zM 이다(위치 파일과 같음 확인). 치수는 파일 값이다(냉동 188×450×420, 냉장 161×450×420 — 없어지는 칸과 같다). slotCount 1.
     - pickSequence 는 넣지 않는다. 서버 안에서만 쓰는 표시값이다.
  2. **없어지는 칸 1,045(F-A6-* 450, C-B7-* 595)의 재고를 새 칸으로 옮긴다** — 위치 정정(stock-corrections), 총량은 그대로.
     - 상품 하나는 새 칸 하나로 간다. 같은 온도대 새 랙의 **3단 1칸**부터 차례로 쓴다. 예전 칸도 모두 3단 1칸이었다.
     - 예약·배정·보류가 걸린 상품은 옮기지 않는다(지금은 없음).
     - **사용자 승인 번호가 있을 때만 옮긴다**: `PMART_APPROVAL_REF=<번호>`. 없으면 옮길 목록만 보여 주고, 재고가 있는 칸은 열어 둔다.
  3. **비어 있는 없어지는 칸은 CLOSED**. 기록은 남고, 폐지(RETIRED)는 하지 않는다.
  - 기존 칸 6,480개의 위치는 `r34` 가 바꾼다. 위치 파일 사본을 c6745ab 로 바꿨다.
  - 다시 돌려도 된다. 이미 등록된 칸은 건너뛰고, 이미 새 칸에 있는 상품은 그 칸으로 보낸다.
- **미리 보기 `r35plan`**: 쓰기 없이 숫자만 보여 준다.
- **`layout.json`(요청 4)**: 냉동·냉장 피킹 랙 230개와 그 칸 7,525개를 c6745ab `buildLayout()` 결과(`tools/dump.mts`)로 바꿨다. A06·B07 줄이 없어졌다.
  - 랙 수 368 과 선반 칸 14,559 는 그대로다.
  - 상온·구역·보충재고 팔레트 등 나머지는 그대로다. 그래서 이 파일의 좌표는 냉동·냉장 랙만 새 평면이고 나머지는 옛 평면이다.
  - LAN 위치는 위치 파일이 정본이다. 도면 그림(`floorplan.svg`)은 다시 그리지 않았다.
  - `mfc_layout_v2.py` 미리 보기(읽기만)도 새로 등록 1,045, 닫을 칸 1,045 로 같은 결과다.

## 2. 없어지는 칸의 재고 — 옮기려면 사용자 승인이 필요하다

## 3. 실행(PC 1) — 순서
1. 승인 없이 먼저: `python -I deploy/lan/seed/mfc_layout.py r35 r34`
   - 예상: 새 칸 새로 1,045. 옮길 줄 79(옮기지 않음). 없어지는 칸 닫음 1,017, 재고가 있어 열어 둠 28.
   - r34: 바꿈 6,480(ACTIVE 6,446, CLOSED 34), 그대로 9,054, 서버에 없음 0, 실패 0.
2. 사용자 승인 뒤: `PMART_APPROVAL_REF=<번호> python -I deploy/lan/seed/mfc_layout.py r35`
   - 예상: 28칸 79줄 옮김, 남은 28칸 닫음. 새 칸은 이미 있음 1,045.
   - 승인을 먼저 받으면 한 번에 `PMART_APPROVAL_REF=<번호> … r35 r34` 로 해도 된다(닫음 1,045).
- 열어 둔 28칸은 옮기기 전까지 옛 좌표로 남는다. 위치 파일에 없어서 r34 가 건드리지 않는다.
